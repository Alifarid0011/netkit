# Changelog

Initial Linux workbench: read-only diagnostics/dashboard, bounded tcpdump capture and offline decode, foreground reverse proxy, nftables plans and owned-rule management with foreground timed cleanup, experimental RouterOS REST client, and explicit Tor SOCKS checks. Source has no third-party Go dependencies. See README for validation boundaries and unsupported operations.
