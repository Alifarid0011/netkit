# Changelog

## 0.2.0 — 2026-11-01

Replace the display-only dashboard with a keyboard-operated workbench: immediate arrow/Tab navigation, editable forms for existing tools, masked router passwords, asynchronous cancellable operations, per-tool results, bounded live output and scrollable confirmation/help. Opening `netkit` on a terminal now launches the workbench; non-terminal help/CLI behavior is preserved. Long fields and resized terminals are supported. Mutation requires explicit confirmation; stopping and quitting retain cleanup semantics. Bubble Tea, Bubbles and Lip Gloss now provide terminal behavior; archives include third-party license notices.

## 0.1.0 — 2026-11-01

Initial Linux workbench: read-only diagnostics/dashboard, bounded tcpdump capture and offline decode, foreground reverse proxy, nftables plans and owned-rule management with foreground timed cleanup, experimental RouterOS REST client, and explicit Tor SOCKS checks. Source has no third-party Go dependencies. See README for validation boundaries and unsupported operations.
